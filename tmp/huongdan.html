🛠️ Cài đặt và Cấu hình

💡 Lưu ý quan trọng: Ollama chạy mặc định trên port 11434. Nếu máy ảo của bạn được firewall chặn từ mạng công cộng, bạn cần mở cổng này hoặc thay bằng IP cục bộ.

Bước 1: Import thư viện

Khi chạy flutter pub get, hãy đảm bảo có thư viện dio:

dependencies: dio: ^5.6.0 http: ^1.3.0 logger: ^2.0.2 flutter: uses-material-design: true

Bước 2: Tạo Service

Tạo file lib/services/ollama_service.dart với cấu trúc dưới đây:

import 'package:dio/dio.dart'; import 'package:flutter/services.dart'; import 'package:logger/logger.dart'; class OllamaService { // Cấu hình đường dẫn // Lưu ý: Thay bằng IP thực tế của máy ảo (ví dụ: 192.168.1.5) // Nếu máy ảo mở cổng từ bên ngoài, có thể dùng domain: 'https://your-vm.com' final baseUrl = 'http://localhost:11434'; // Khởi tạo Dio và Logger final _dio = Dio(); static final logger = Logger(); // Hàm kiểm tra kết nối (Ping) Future isServerOnline() async { try { // Gọi endpoint /api/tags để lấy danh sách models // Dio sẽ tự động kiểm tra kết nối và trả về lỗi nếu không có kết nối final response = await _dio.get( '$baseUrl/api/tags', timeout: const Duration(seconds: 10), connectTimeout: const Duration(seconds: 5), ); // Nếu trạng thái HTTP là 200, nghĩa là kết nối thành công if (response.statusCode == 200) { logger.d('✅ Kết nối thành công với Ollama Server.'); return true; } else { logger.e('⚠️ Kết nối thành công nhưng không có dữ liệu (${response.statusCode}).'); return false; } } catch (e) { // Xử lý các lỗi kết nối: Timeout, Connection Refused, DNS Failure logger.e('❌ Không thể kết nối đến Ollama Server: $e'); return false; } } // Hàm gọi LLM (Ví dụ: Chat) Future> generateResponse(String model, String prompt) async { try { // Cấu hình request final options = Options( headers: { 'Content-Type': 'application/json', }, ); final response = await _dio.post( '$baseUrl/api/generate', data: { 'model': model, 'prompt': prompt, 'stream': false, // false để nhận kết quả hoàn chỉnh 'temperature': 0.7, }, options: options, connectTimeout: const Duration(seconds: 30), ); // Kiểm tra mã trạng thái if (response.statusCode == 200) { final data = response.data as Map; // Ollama trả về kết quả nằm trong key 'response' return { 'output': data['response'] as String?, 'done': data['done'] as bool? }; } else { throw Exception('Server Error: ${response.statusCode}'); } } catch (e) { // Log chi tiết từ DioException logger.e('🚫 Lỗi Dio: ${e.runtimeType}'); if (e is DioException) { logger.e('Status Code: ${e.response?.statusCode}'); logger.e('Message: ${e.message}'); } return null; } } }

🚨 Xử lý các lỗi thường gặp (Troubleshooting)

Dưới đây là bảng phân tích các lỗi phổ biến và cách khắc phục khi dùng Dio với Ollama:

Lỗi (Error) Nguyên nhân Giải pháp / Hành động
Connection Refused Máy ảo không phản hồi yêu cầu kết nối.
  • Kiểm tra Firewall trên máy ảo: Đã mở cổng 11434 (TCP) cho IP của bạn chưa?
  • Kiểm tra Địa chỉ IP trong code có đúng với máy ảo không?
Connection Timeout Máy ảo không trả lời trong thời gian chờ (timeout).
  • Tăng tham số connectTimeout trong Dio từ 10s lên 30s.
  • Kiểm tra mạng giữa máy chủ app và máy ảo (Firewall router, Corporate Network).
SSL Certificate Error Máy ảo đang chạy HTTP nhưng bạn cố gắng kết nối qua HTTPS, hoặc chứng từ không khớp.
  • Đảm bảo URL bắt đầu bằng http:// nếu chưa cài đặt SSL trên Ollama server.
  • Hoặc kiểm tra lại địa chỉ của máy ảo.
DNS Lookup Failed Không tìm thấy IP khi sử dụng tên miền.
  • Thay tên miền bằng IP trực tiếp trong biến baseUrl.

💡 Mẹo "Pro" khi làm việc với Ollama trên Cloud

⚠️ Vấn đề Firewall Ollama thường chạy lokal (chỉ cho localhost). Để gọi từ Flutter app trên web hoặc app khác, bạn gặp vấn đề Network Isolation.

Cách 1: Mở cổng trên Cloud (AWS/GCP/Azure)

1. Truy cập vào Console Cloud của máy ảo.
2. Tìm trang Security Groups hoặc Firewall.
3. Thêm Rule mới:

Type TCP
Port Range 11434 - 11434
Action Allow
Source 0.0.0.0/0 (Hoặc IP của bạn)

Cách 2: Sử dụng IP localhost (Chỉ nếu trong cùng mạng LAN)

Nếu app và máy ảo đang trong cùng mạng Wi-Fi/LAN, hãy thay thế localhost trong code bằng IP của máy ảo:

// Thay đổi dòng này String baseUrl = 'http://192.168.1.50:11434'; // Thay vì String baseUrl = 'http://localhost:11434';
