Create `db/migrations/007_question_stats_trigger.sql` with:

1. **Trigger function `fn_update_question_stats()`** (SECURITY DEFINER, plpgsql):
   - Guard: `IF NEW.final_score IS NULL THEN RETURN NEW; END IF;` (skip ungraded essays)
   - Lookup `question_id` from `assignment_questions`:
     ```sql
     SELECT aq.question_id, aq.points INTO v_question_id, v_points
     FROM assignment_questions aq WHERE aq.id = NEW.assignment_question_id;
     ```
   - Guard: `IF v_question_id IS NULL THEN RETURN NEW; END IF;` (D-07: skip custom questions)
   - Determine correctness: `v_is_correct := (NEW.final_score = v_points);`
   - UPSERT into `question_stats`:
     ```sql
     INSERT INTO question_stats (question_id, total_attempts, correct_count, avg_score, last_attempted)
     VALUES (
       v_question_id,
       1,
       CASE WHEN v_is_correct THEN 1 ELSE 0 END,
       NEW.final_score / NULLIF(v_points, 0),
       now()
     )
     ON CONFLICT (question_id)
     DO UPDATE SET
       total_attempts = question_stats.total_attempts + 1,
       correct_count = question_stats.correct_count + CASE WHEN v_is_correct THEN 1 ELSE 0 END,
       avg_score = (question_stats.avg_score * question_stats.total_attempts + NEW.final_score / NULLIF(v_points, 0)) 
                   / (question_stats.total_attempts + 1),
       last_attempted = now();
     ```
   - `RETURN NEW;`

   Declare variables at top: `v_question_id uuid; v_points numeric; v_is_correct boolean;`

2. **Trigger definition:**
   ```sql
   CREATE TRIGGER trg_sa_02_question_stats
     AFTER INSERT ON submission_answers
     FOR EACH ROW
     EXECUTE FUNCTION fn_update_question_stats();
   ```

Name prefix `trg_sa_02_` ensures it fires after skill mastery trigger (alphabetical order per Research pitfall 1).

Deploy via Supabase MCP `execute_sql`.
