# Phase 3: Rubric System — UI Design Contract

> Visual and interaction contract for all rubric-related UI components. Generated by gsd-ui-researcher. All values reference existing design tokens from `lib/core/constants/design_tokens.dart`.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Flutter Material 3 + Custom Design Tokens |
| Preset | not applicable (Flutter, not shadcn) |
| Component library | Flutter Material + project DesignTokens |
| Icon library | Material Icons (flutter built-in) |
| Font | System default (Vietnamese-compatible) |
| Token file | `lib/core/constants/design_tokens.dart` |

---

## Spacing Scale

Uses existing `DesignSpacing` tokens. All values in logical pixels (dp). Only multiples of 4 used.

| Token | Value | Usage in This Phase |
|-------|-------|---------------------|
| `DesignSpacing.xs` | 4dp | Icon-to-text gap in level cards, inline badge padding |
| `DesignSpacing.sm` | 8dp | Between level cards, between criterion header items |
| `DesignSpacing.md` | 12dp | Between criteria in list, internal card padding (compact) |
| `DesignSpacing.lg` | 16dp | Screen edge padding, card content padding, section spacing, grader divider height |
| `DesignSpacing.xxxl` | 28dp | Between major sections (criteria list vs. action buttons), top padding inside full-screen bottom sheet |

Exceptions: `DesignSpacing.xl` (18dp) and `DesignSpacing.xxl` (22dp) exist in token file but are NOT used in this phase because they are not multiples of 4.

---

## Typography

Uses existing `DesignTypography` predefined TextStyles. This phase uses exactly 4 font sizes and 2 font weights.

**Font sizes (4):** 12sp, 14sp, 16sp, 20sp
**Font weights (2):** regular (w400), semiBold (w600)

| Role | Token | Size | Weight | Line Height | Usage |
|------|-------|------|--------|-------------|-------|
| Score display / Sheet title | `DesignTypography.headlineMedium` | 20sp | semiBold (w600) | 1.4 | "X/Y diem" in grading, "Thiet lap Rubric" header, "Chon Template" header |
| Section header / Button text | `DesignTypography.titleMedium` | 16sp | semiBold (w600) | 1.4 | Criterion name display, summary button text |
| Body content | `DesignTypography.bodyMedium` | 14sp | regular (w400) | 1.5 | Level descriptions, form labels |
| Caption / Label | `DesignTypography.caption` | 12sp | regular (w400) | 1.4 | Points badge, helper text, locked state label, button labels, chip text |

**Weight override rule:** When a caption/label element needs emphasis (e.g., points chip in viewer, points input in builder), apply `fontWeight: FontWeight.w600` inline override to the base caption style. Do NOT use w500 or w700 anywhere in this phase.

**Migration from previous spec:**
- `DesignTypography.titleLarge` (18sp, w700) -> replaced by `DesignTypography.headlineMedium` (20sp, w600) for sheet titles
- `DesignTypography.labelMedium` (12sp, w500) -> replaced by `DesignTypography.caption` (12sp, w400) with w600 override where emphasis needed
- `DesignTypography.bodyLarge` (16sp, w400) -> replaced by `DesignTypography.titleMedium` (16sp, w600) for button text that needs emphasis, or keep as `titleMedium` since both are 16sp

| Role | Token | Value | Usage |

## Copywriting Contract

All copy is Vietnamese as per project standard.

### Primary Actions

| Element | Copy |
|---------|------|
| Add rubric CTA (empty) | "Them Rubric" |
| Rubric configured summary | "Rubric: Da cau hinh {N} tieu chi (Nhan de sua)" |
| Rubric locked summary | "Rubric: {N} tieu chi (Chi xem)" |
| Save rubric button | "Luu Rubric" |
| Save template button | "Luu thanh Template" |
| Load template button | "Chon tu Template" |
| View criteria button (student) | "Xem Tieu chi" |
| Add criterion button | "+ Them tieu chi" |
| Add level button | "+ Them muc diem" |
| Delete criterion | Icon only (trash) + confirmation dialog |
| Delete level | Icon only (close/x) — no confirmation for levels |

### Empty States

| Context | Heading | Body |
|---------|---------|------|
| Rubric builder (no criteria yet) | "Chua co tieu chi nao" | "Nhan '+ Them tieu chi' de bat dau xay dung rubric cho cau hoi nay." |
| Template picker (no templates) | "Chua co template nao" | "Luu rubric hien tai thanh template de tai su dung sau." |
| Student rubric viewer (no rubric) | (not rendered) | Component simply not shown when `rubric == null` |
| Grading rubric (no rubric on question) | (not rendered) | Falls back to manual score input (existing behavior) |

### Error States

| Context | Message |
|---------|---------|
| Publish validation — missing rubric | "Cau hoi tu luan phai co Rubric truoc khi phat hanh. Nhan vao cau hoi de them Rubric." |
| Publish validation — incomplete rubric (< 2 levels) | "Moi tieu chi phai co it nhat 2 muc diem." |
| Criterion name empty | "Vui long nhap ten tieu chi." |
| Level points empty | "Vui long nhap diem cho muc nay." |
| Level description empty | "Vui long nhap mo ta cho muc diem nay." |
| Template save — name empty | "Vui long nhap ten template." |
| Override reason empty (D-04) | "Vui long nhap ly do ghi de diem." |

### Destructive Actions

| Action | Confirmation Copy |
|--------|-------------------|
| Delete criterion | WarningDialog: "Xoa tieu chi '{name}'? Toan bo muc diem trong tieu chi nay se bi xoa." Buttons: "Xoa" (error color) / "Huy" |
| Delete template | WarningDialog: "Xoa template '{name}'? Hanh dong nay khong the hoan tac." Buttons: "Xoa" / "Huy" |
| Override score (D-04) | Inline prompt (not dialog): TextFormField "Ly do ghi de" + "Xac nhan" button. Reason is mandatory. |

```
if !isLocked:
  Padding (horizontal: DesignSpacing.lg)

      borderRadius: DesignRadius.sm

```

**_buildAddLevelButton():**
```
if !isLocked:
  Padding (top: DesignSpacing.sm)
    TextButton.icon
```

**_buildBottomActions():**
```
Container
  padding: DesignSpacing.lg
  decoration: BoxDecoration(border: Border(top: DesignColors.dividerLight))

```

**Interaction states:**

| State | Visual |
|-------|--------|
| Empty (no criteria) | Empty state illustration area + "Chua co tieu chi nao" text + add button |
| Editing | All fields enabled, level cards white, add/delete visible |
| Locked (D-09) | All fields disabled, text color: `DesignColors.textTertiary`, no add/delete buttons, warning banner at top |
| Validation error | Red border on invalid fields (`DesignColors.error`), error text below field in `DesignTypography.caption` color `DesignColors.error` |
| Loading (template load) | `ShimmerLoading` over criteria list area |

**Animation:** Bottom sheet opens with `DesignAnimations.durationNormal` (300ms), `Curves.easeInOut`. Criterion expand/collapse: `AnimatedCrossFade` with `DesignAnimations.durationFast` (150ms).

**New criterion default:** When user taps "+ Them tieu chi", pre-populate 2 levels:
- Level 1: points = 5 (placeholder), description = "" (empty, user fills)
- Level 2: points = 0 (0-point floor, per Claude's Discretion), description = "" (empty)

### 2. ReadOnlyRubricViewer (Dumb Component)

**Source decision:** D-03

**File:** `lib/widgets/rubric/read_only_rubric_viewer.dart`

**Props:**

**_buildCriterionSection(criterion, selectedLevelIndex):**
```
Column (crossAxisAlignment: start)
  Row
    Expanded: Text criterion['name'] (DesignTypography.titleMedium, fontSize: 14sp override)

      background: DesignColors.primary.withOpacity(0.12)
```

**_buildLevelItem(level, isSelected):**
```
Container
  margin: EdgeInsets.only(bottom: DesignSpacing.xs)

    color: isSelected ? DesignColors.primary.withOpacity(0.08) : DesignColors.white

    if isSelected: Icon(Icons.check_circle, color: DesignColors.primary, size: DesignIcons.smSize)
```

**Layout (compact=true, for assignment detail preview card):**
```
Column
  for each criterion:
    Padding (bottom: DesignSpacing.xs)
      Row
        Icon(Icons.check_circle_outline, DesignIcons.xsSize, color: DesignColors.tealPrimary)
```
