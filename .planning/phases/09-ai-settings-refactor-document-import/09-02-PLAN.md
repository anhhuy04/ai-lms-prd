  <context>
Phase 9 requires teachers to pick `.xlsx` and `.docx` files from device storage. `file_picker` is the standard Flutter package for this. It is NOT currently in pubspec.yaml.

**Required changes if approved:**
- `pubspec.yaml`: add `file_picker: ^11.0.2` under dependencies
- `android/app/src/main/AndroidManifest.xml`: add READ_EXTERNAL_STORAGE permission (API < 33) or READ_MEDIA_DOCUMENTS (API ≥ 33)
- `ios/Runner/Info.plist`: add `NSPhotoLibraryUsageDescription` key

**Usage pattern (from RESEARCH.md Pattern 9):**
```dart
final result = await FilePicker.platform.pickFiles(
  type: FileType.custom,
  allowedExtensions: ['xlsx', 'docx'],
  withData: true,  // REQUIRED — loads bytes into memory
);
if (result != null) {
  final bytes = result.files.single.bytes!;
  final filename = result.files.single.name;
}
```

**Why `withData: true` is required:** File path access is unreliable on Android (scoped storage). Bytes are always available regardless of platform.

**Alternative**: `image_picker` — Not applicable (only handles images/videos).

**Step 3: Android permissions**
In `android/app/src/main/AndroidManifest.xml`, inside `<manifest>` tag before `<application>`:
```xml
<!-- file_picker: Read external storage (API < 33) -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />
<!-- file_picker: Read media (API >= 33) -->
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
```

Note: For document access on modern Android, file_picker uses the system document picker — no special permissions needed beyond what the manifest declares.

**Step 4: iOS Info.plist (if not already present)**
